# Power / AI · 本地电力电子文献台

首次使用先双击 **setup.cmd**，安装 Python 3.10+、Ollama 并下载本地 `qwen2.5:1.5b` 模型；随后双击 **start.cmd**。日后只需运行 start.cmd。程序没有 pip 依赖。安装脚本使用 Windows Package Manager（winget），需要网络和足够磁盘空间。

网页仅监听 `127.0.0.1`，启动脚本携带本机随机口令建立浏览器会话，无云端账号或服务器。口令保存在 `data/access-token.txt`，请不要分享。这个版本依靠 Windows 账号保护本机文件，不是多用户服务，也不支持手机跨设备同步。

## 每次打开会发生什么

1. 启动本机服务，浏览器立即显示已有论文。
2. 后台采集题录、去重并补全可免费获取的摘要，**全程不调用 AI，不使用你的 AI 额度**。首次从最近 12 个月开始建立档案。
3. 之后再次双击启动脚本，会复用正在运行的服务并触发更新。页面中也有“检查更新”按钮。
4. 需要中文内容时，点击页面的 **“生成译名与概括”**，才会调用已配置的 AI；只补全缺少的译名或概括，已有内容保留。待补全为 0 时按钮禁用，不会调用 AI。
5. 更新失败时保留全部本地数据，来源状态分别显示失败或覆盖受限。

请保持启动窗口打开。关闭网页不会停止程序；关闭启动窗口会停止程序。首次采集可能需要较长时间，尤其中文官网响应较慢时。此版改为**打开时更新**，不再承诺每天 08:00 自动更新；电脑关闭时不会采集。

## 收录范围

- TIE、TII、TPEL、中国电机工程学报、电工技术学报、自动化学报，研究论文和综述均收。
- 只筛选电力电子与 AI 的交叉研究，故障检测/诊断/定位独立页面；数字孪生单独标签，但也必须包含 AI。
- 付费论文同样收录题名、中文译名和原文链接，**不下载 PDF，不购买订阅**。没有公开摘要就不生成概括。
- 搜索、期刊/主题/日期筛选、收藏、已读记录、JSON 导出。收藏和已读保存于 SQLite 数据库，不依赖浏览器缓存。

公开版不附带个人论文库。首次打开后，程序自行采集可访问的公开题录；来源受限时会单独提示，不能视作六种期刊近 12 个月已完整补齐。

## 免费来源的实际边界

- IEEE 三刊读取 Crossref 公开登记元数据（不需要 API Key）；自动化学报读取官网优先发表、当期和过刊目录。摘要和首次在线日期是否存在取决于出版方。在线日期缺失时会明确展示其他日期依据，绝不把注册、修改日期当作首次发表。
- 自动化学报官网未发送完整的 TLS 证书链。压缩包附带已验证的公开 Sectigo 中间证书 `aas-intermediate.pem`，仅供连接该官网时补齐证书链；程序仍验证站点证书和域名。
- 中国电机工程学报读取官网分页列表；部分记录只有年份。年份级记录在 12 个月边界附近无法精确筛除，会标注精度到年，需要核对原文。该来源显示“覆盖受限”。
- 电工技术学报读取官网优先发表/当前及上一期目录。该站在实测中多次超时，程序会说明无法核验完整历史；不会把请求失败当作没有论文。
- 此程序是基于关键词的筛选工具，有漏检或误检可能，不是期刊完整性审计。Early Access 如果没有进入公开元数据，可能延迟收录。
- 同 DOI 合并且保留收藏与已读。历史全量扫描发现、且有明确日级发表日期的旧论文标记为“补收录”；年份/月度日期不据此推断为补收录。
- 若你已有 IEEE 官方 Metadata API Key，可以通过环境变量 `IEEE_API_KEY` 提供，用来补取摘要。程序不申请、购买密钥，也不会输出密钥。

## 本机免费 AI：手动生成

网站默认只使用 Ollama 本机模型，不会回退到 Codex 或调用云端付费 API。打开网站、检查更新、检索和收藏均不调用模型；需要中文内容时点击“生成译名与概括”。没有公开摘要的论文只翻译题名，不编造概括。已生成的内容保存在本机数据库中。

首次使用双击 `setup.cmd`，脚本按需通过 winget 安装 Python 与 Ollama，再下载 `config.json` 指定的模型。默认 `qwen2.5:1.5b` 的模型文件约 1 GB；运行速度取决于电脑硬件。安装脚本可重复执行，已安装的组件不会重复安装。模型只在安装时下载，压缩包内不含模型本体。接收者需要自己运行安装脚本。

每次点击最多生成 120 篇，每批处理 1 篇；可在 `config.json` 调整。中文概括目标为 150—250 字，长度不符会标记。首次导入多篇论文时，可能需要多次点击。若本机 Ollama 未启动或模型缺失，页面保留题录与待生成状态，可重新运行 setup.cmd。

## 更新范围

空数据库首次启动会扫描近 12 个月。之后日常打开网站或点击“检查更新”时，只查询北京时间当天变更的 Crossref 元数据；新收录的 IEEE 论文须有今天的日级发表日期。已收录论文即使之后分配卷期，仍按 DOI 更新原记录。中国电机工程学报只检查官网今天发布的列表记录；电工技术学报只检查当前的优先发表和近期目录；自动化学报只检查优先发表和当期目录。新增论文须有今天的日级在线发表日期，唯中国电机工程学报官网仅有年份时按官网今天发布的列表记录判断。无法取得在线日期的记录仍会标明日期依据。已有历史论文不会每天重新当作新增。

如需主动重扫近 12 个月，在项目目录运行 `python app.py --update-only --backfill`。这一历史扫描可能新增带“补收录”标记的论文，需数分钟；受限来源仍不能保证完全覆盖。

安装依据：[Ollama Windows 下载](https://ollama.com/download/windows)、[Qwen2.5 模型](https://ollama.com/library/qwen2.5/tags)。

## 文件与备份

转发给他人请使用 `power-ai-papers-share-safe.zip`。它只包含程序、配置和说明，不含 `data` 文件夹、访问口令、收藏或已读记录。不要直接转发整个项目目录或带数据库的个人压缩包。

发布到 GitHub 时可使用 `power-ai-papers-github-safe.zip` 中的文件创建**新仓库**。压缩包包含源码、测试和 `.gitignore`，不含 `data`、本机日志和访问口令。不要把你现有的 `data` 文件夹、浏览器导出的 JSON 或个人论文库备份上传；GitHub 上删除文件也不会自动清除已经提交的历史记录。

分享包附带 `power-ai.ico`，可用于 Windows 桌面快捷方式。若关闭 VPN 后本机代理拒绝连接或返回网关错误，采集器会尝试直连公开题录接口；目标网站本身不可达时仍会在来源状态中报告失败。

| 文件 | 用途 |
| --- | --- |
| `setup.cmd / setup.ps1` | 首次安装 Python、Ollama 和模型 |
| `start.cmd` | 双击启动并检查更新 |
| `app.py` | 标准库采集器、本机服务、AI 适配 |
| `index.html / style.css / app.js` | 本地网页 |
| `config.json` | 端口、采集及 AI 配置 |
| `data/papers.sqlite3` | 论文、收藏、已读及来源状态 |
| `data/app.log` | 采集运行日志 |

备份前先关闭启动窗口，再复制整个 `data` 文件夹，避免遗漏 SQLite 的 WAL 文件。不要把含本机访问口令的 data 文件夹公开。

仅更新题录和公开摘要（不调用 AI、不打开网页）：`python app.py --update-only`。离线浏览：`python app.py --no-update`。验证：`python -m unittest -v`。

免费元数据接口文档：[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)。
